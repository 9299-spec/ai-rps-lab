# AI 猜拳实验室

适用于小学高年级的浏览器 AI 实验：采集自己的手势照片、训练两个模型、用独立照片比较效果、教机器胜负规则，再与电脑猜拳。

## 使用

打开 GitHub Pages 网址，允许使用摄像头。每类至少 5 张照片可试训，建议 20—30 张；照片和训练模型只保存在当前页面内存中，刷新后清空。电脑在倒计时前随机选好手势，结束时锁定孩子的画面并亮拳，识别后按孩子提交的规则自动计分。

## 本地预览

在此目录运行 `python -m http.server 8765`，打开 `http://localhost:8765`。摄像头需要 HTTPS 或 localhost。

## GitHub Pages

在仓库 Settings → Pages，选择 Deploy from a branch，使用 main 分支的根目录 / (root)。所有文件均为静态资源，无需服务器或 API 密钥。

## 组件与原理

使用 TensorFlow.js 4.22.0 与预训练 MobileNet v1 0.25 模型进行特征提取，孩子的照片训练一个新的三类分类器。模型、权重和运行库随网站加载；手部照片不会上传。预测分数不是正确保证，空画面和陌生手势也可能被误认。

- TensorFlow.js：https://github.com/tensorflow/tfjs （Apache-2.0）
- MobileNet 模型项目：https://github.com/tensorflow/tfjs-models/tree/master/mobilenet （Apache-2.0）

## 手部关键点

开启摄像头后，可显示每只手最多 21 个关节点及连线。点编号可开关。MediaPipe Hand Landmarker 在独立工作线程运行；此预训练模型用于可视化，孩子训练的分类器仍负责猜拳识别。模型和运行文件随网页加载，照片不上传。

MediaPipe：https://github.com/google-ai-edge/mediapipe （Apache-2.0）。

## AI 体感运动会（motion/）

运动页现为三个独立项目，替换原先摘星星、护盾、森林三关：

- **墙来了**：孩子为三个不同姿势命名，每类至少采集 8 个身体关键点样本；3 秒准备后连采 10 个，可换人补充至每类 60 个。按身体比例归一化后，用标注样本训练近邻分类器；距离过远或类别相近会显示“不确定”。不保存照片。可清空某类、换新姿势，再训练。
- **高抬腿计数赛**：左右交替，膝盖接近髋部，再落脚计一次；完整循环、稳定持续时间和追踪丢失保护。
- **开合跳计数赛**：双臂举高且双脚打开，再回到手臂放下、双脚合拢才计一次；不单独判定腾空。

选手姓名/队名、15/30/45 秒、倒计时、试做、暂停、自动结算、同分并列排行榜。项目/时长/模型版本/示范模式分榜；同组墙题目顺序相同。墙每 5 秒到达，到达前稳定识别正确姿势至少约 0.35 秒才得分。老师可在结果中更正误判并说明原因，榜单显示更正。结束未完成比赛不入榜。

身体识别由原有 MediaPipe Tasks Vision 0.10.14 与 Pose Landmarker Lite 提供。仅墙来了训练孩子的新姿势分类器；两个计数项目由关键点规则判断。不是专业体态评估。所有样本、模型和成绩存在页面内存中，刷新清空；无录制或画面上传。比赛结束保留摄像头给下一位，课堂结束请手动关闭。

代码：motion/sports-core.mjs（分类器、计数和排名），sports.mjs（摄像头、训练和比赛交互），sports.css、index.html。旧版 app.mjs/movement.mjs/motion.css 已不被页面引用。

验证：36 项核心断言覆盖完整计数、交替、未完成动作、追踪中断、分类器/未知姿势/归一化、模型快照和排名。另以本地模拟摄像头及骨架运行浏览器流程测试；这些测试文件不发布，不代表真人动作准确率。身体模型与运行库沿用已验证的本机组件。
